# AI Creator — форма заявки без онлайн-оплати

Готова статична сторінка форми AI Creator у палітрі основного сайту Коваленко.

## Завантаження на хостинг

Завантажте весь вміст папки `dist` у кореневу папку сайту. Проєкт не потребує збірки, Node.js або сторонніх CDN.

Після публікації основна форма відкривається в корені. Папка `thank-you` збережена в комплекті як резерв попередньої платіжної версії, але нова форма на неї не перенаправляє.

## CRM та аналітика

Копія підключена до того самого обробника AmoCRM, що й оригінальна сторінка:

`https://mufiksoft.com/shopifyband/amo-panel/forms.php`

Передаються пакет, ім’я, email, міжнародний номер телефону, месенджер, UTM-мітки та технічне джерело `packagesai_no_payment`. Платіжні параметри, бронювання й перенаправлення на оплату не передаються. Після успішної відправки підтвердження показується безпосередньо у формі.
