# AI Creator — форма заявки без онлайн-оплати

Готова статична сторінка форми AI Creator у палітрі основного сайту Коваленко.

## Завантаження на хостинг

Завантажте весь вміст папки `dist` у кореневу папку сайту. Проєкт не потребує збірки, Node.js або сторонніх CDN.

Після успішного створення заявки в CRM форма автоматично відкриває локальну сторінку `thank-you/`. Перехід не запускає оплату.

## CRM та аналітика

Копія підключена до того самого обробника AmoCRM, що й оригінальна сторінка:

`https://mufiksoft.com/shopifyband/amo-panel/forms.php`
